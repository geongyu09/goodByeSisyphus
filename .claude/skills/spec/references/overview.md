# 코치님 롤링페이퍼: Next.js + Notion 개발 가이드

코르크보드 프로토타입(`Prototype.dc.html`)을 Next.js 서버에서 Notion API를 호출하는 구조로 옮길 때 필요한 지식을 한 문서에 모았습니다. 정보는 2026년 10월 기준 Notion 공식 문서와 Next.js 16 문서를 확인해서 작성했으며, 버전이 올라가면 일부 API 이름이 바뀔 수 있으므로 마지막의 참고 링크에서 다시 확인하시기 바랍니다.

---

## 1. 전체 구조

```
[브라우저: React 클라이언트 컴포넌트]
        │  Server Action 호출 (메모 쓰기, 스티커 붙이기·떼기)
        ▼
[Next.js 서버 (Vercel 배포 시 서버리스 함수)]
        │  NOTION_TOKEN은 서버 환경 변수에만 존재
        │  보드 데이터는 'use cache'로 캐시
        ▼
[Notion API] ──▶ [Notes 데이터 소스] ◀─relation─ [Stickers 데이터 소스]
```

- 브라우저는 Notion을 직접 호출하지 않고 Server Action만 호출하기 때문에, 토큰은 서버 밖으로 나가지 않습니다.
- 보드 전체(메모와 스티커)는 서버에서 한 번 불러와 캐시하고, 검색·정렬·더 보기는 프로토타입처럼 클라이언트에서 처리합니다.
- 쓰기 요청이 들어오면 Notion에 저장한 뒤 캐시 태그를 무효화해서 다음 조회 때 새 데이터를 가져옵니다.
