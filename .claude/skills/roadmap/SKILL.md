# roadmap

로드맵: [ROADMAP.md](ROADMAP.md) — 반드시 먼저 읽는다.
규칙: `.claude/rules/ssot.md` — 문서가 SSOT다.

## 모드 (`$ARGUMENTS`)

- **next** (기본값): ROADMAP.md에서 첫 번째 미완료 작업을 고른다.
  1. 작업의 근거 문서 섹션을 읽는다.
  2. 사용자에게 작업 내용과 계획을 짧게 공유한 뒤 구현한다.
  3. 해당 Phase의 완료 조건 및 문서 명세와 대조해 검증한다.
  4. 완료되면 체크박스를 `[x]`로 바꾼다. Phase의 모든 작업이 끝나면 완료 조건을 확인하고 보고한다.
- **status**: Phase별 진행률, 다음 작업, 미결정 사항을 요약한다.
- **sync**: 기반 문서(`.claude/skills/spec/references/`)를 다시 읽고 ROADMAP.md와 비교한다. 문서에 추가/변경/삭제된 내용을 반영해 로드맵을 갱신하고, 변경된 문서 기준으로 이미 완료된 작업 중 다시 손봐야 할 것을 새 작업으로 추가한다.
- **작업명**: 해당 작업을 찾아 next와 같은 절차로 진행한다.

## 원칙

- 구현 중 문서와 다른 방향의 요청을 받으면 구현을 멈추고 SSOT 규칙 2번 절차(문서 먼저 수정)를 따른다. 문서가 바뀌면 sync를 수행한다.
- 로드맵에 없는 작업 요청은 근거 문서가 있는지 확인한다. 있으면 로드맵에 추가 후 진행, 없으면 문서부터 갱신한다.
- 로드맵에 문서 내용을 복사하지 않고 포인터만 둔다.
